Strengths & Weaknesses of Classical Occlusion Culling Algorithms
Research
M.Sc. Thesis  ·  Universität Paderborn  ·  2024

An empirical study comparing five classical occlusion culling algorithms for real-time 3D rendering — a technique used in games and simulations to skip rendering geometry hidden behind other objects. The study revealed a surprising finding about how these decades-old algorithms perform on modern GPU hardware.

  • Implemented three algorithms (PLP, CPLP, SOOQ) from scratch in C++ within the PADrend rendering engine; CHC and CHC++ benchmarked from existing implementations
  • Tested all five algorithms across 5,000 rendered frames using complex 3D scenes (Power Plant, Pompeii, AutoFabrik), recording frame duration, triangle count, and occlusion query metrics per frame
  • Key finding: frame duration correlated directly with scene complexity, not with the number of occlusion queries — contradicting the core assumption behind most of these algorithms
  • Conclusion: on modern GPUs, the overhead these 20-year-old algorithms were designed to minimise is no longer the bottleneck — making their strategies largely equivalent in practice
